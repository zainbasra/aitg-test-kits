AITG Demo Shop: a free practice site for test automation

A small fake shop you can point any testing tool at: Playwright, Selenium, Cypress, codeless tools or AI test agents. Fake data only. Nothing is sold, and nothing you type leaves your browser.

Open the shop   Open the test lab

What you can test

  • Login with a working account, a wrong password and a locked account.
  • Product list with search, category filter, sort and an in-stock filter (12 products, one sold out).
  • Cart: add, change quantity, remove, coupon codes, free-shipping rule, and a confirm dialog to clear it.
  • Checkout form with validation messages for every field, then an order number and an order history.
  • Test lab: an element that appears late, an in-page confirm dialog, an iframe, a button in shadow DOM, a new-tab link, ids that change on every load, a sortable table and a file picker.

Test switches

Turn on a change to see whether your tests, or a tool's self-healing, still pass. Set them on the switches page or in the address:

?delay=1Slow loading (1.5 s).
?flaky=1Random load time from 0 to 3 s, so timing-dependent tests become flaky.
?rename=1"Add to cart" becomes "Add to basket", with a new id and test id.
?look=1Visual change: near-white price, square cards, green button.
?shift=1A promo banner appears late and shifts the layout.

Switches are saved in your browser. Use "Reset shop" in the footer to clear the cart, orders, login and switches.

Practice data

Rules

  • Use it for learning and for testing tools. Keep load light: no load tests, scanners or bots against this site.
  • It is a static site with no server logic, so there is nothing to attack. Security practice belongs on a local app such as OWASP Juice Shop.
  • The shop pages are not indexed by search engines; this page is.

Why it exists

We use it for the hands-on tests on AI Testing Guide, so every tool runs against the same pages. Articles name the shop version they used. Read how we test.
